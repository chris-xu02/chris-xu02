## Principles

- **Retrieve before you generate** — citations and validation on the answer path, not as an afterthought.
- **Idempotent consumers** — at-least-once delivery is a broker feature; exactly-once outcomes are a consumer design.
- **Operable systems** — alerts and traces that shorten the path from symptom to explanation.
